# Horror Screen Effects (Forge 1.20.1)

Мод с экранными эффектами для хоррор-карт. **Нужен и на сервере, и у каждого игрока** (одна и та же версия .jar).

## Как собрать через GitHub
1. Создай репозиторий на GitHub и загрузи ВСЕ файлы из этой папки, сохранив структуру папок
   (включая скрытую папку `.github/workflows/build.yml`; если веб-загрузка её не взяла —
   *Add file → Create new file* и впиши путь `.github/workflows/build.yml`, вставив содержимое).
2. Вкладка **Actions** → **Build mod** → *Run workflow* (или просто сделай commit в ветку main/master).
3. После зелёной галочки открой запуск → внизу **Artifacts → horrorfx-mod** → внутри `horrorfx-1.0.0.jar`.
4. Положи jar в папку `mods` сервера и всех игроков (Forge 1.20.1, 47.2.0+).

## Эффекты
`darkness` затемнение · `blood` кровь + сердцебиение · `robot` глаза робота · `whiteout` белое затемнение ·
`shake` тряска · `blur` размытие · `glow` свечение · `vignette` виньетка · `grain` зернистость · `film` киноплёнка ·
доп.: `flicker` мерцание/строб · `letterbox` кино-полосы · `tint` цветной оттенок · `static` помехи ТВ/глитч

## Управление
* Клавиша **K** (или `/horrorfx gui`) — открывает меню (нужны права оператора, в одиночке — владелец мира).
* В меню: интенсивность, непрозрачность, скорость, размер/радиус, цвет (HEX), появление/затухание, длительность,
  звук (любой ID), громкость, тон, повтор звука, кому отправить (`@a`, `@p`, ник...), превью только у себя.
* **Сохранить в мир** — пресеты лежат в мире (`data/horrorfx.dat`) и едут вместе с картой.
  Команды и командные блоки используют сохранённые пресеты.

## Команды (для командных блоков)
```
/horrorfx start @a blood                 # с пресетом из мира
/horrorfx start @a darkness 1.0 10       # интенсивность 1.0, 10 секунд (длительность включает затухание)
/horrorfx start @p shake 0.8 -1          # -1 = пока не остановят
/horrorfx stop @a blood                  # плавно остановить один эффект
/horrorfx stop @a                        # плавно остановить все
/horrorfx clear @a                       # мгновенно убрать всё
/horrorfx list
```

## Свои звуки
В поле «Звук» можно указать любой ID: `minecraft:entity.warden.heartbeat`, `minecraft:ambient.cave` и т.д.
Для своих .ogg сделай ресурспак карты:
```
assets/mymap/sounds.json
assets/mymap/sounds/scream.ogg
```
```json
{ "scream": { "sounds": [ "mymap:scream" ] } }
```
и впиши в поле `mymap:scream`. Повтор «в такт эффекту» для крови = ритм сердцебиения (зависит от «Скорость»).

## Заметки
* Размытие использует ванильный шейдер blur (5 уровней силы) — шейдерпаки (Iris/Oculus) могут с ним конфликтовать.
* «Свечение» — мягкое аддитивное свечение/засветка по краям, а не полноценный bloom-шейдер.
* GUI рассчитан на масштаб интерфейса GUI Scale ≤ 4.
